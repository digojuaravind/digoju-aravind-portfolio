## Run locally
Open `index.html` in a browser.

## Upload to GitHub
1. Create a new GitHub repository, for example: `digoju-aravind-portfolio`
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Before publishing
- Add your actual GitHub and LinkedIn URLs if you want social profile buttons.
- Replace or update any project links when your project repositories are public.
- Keep `assets/Digoju-Aravind-Resume.pdf` if you want the Resume button to work.
